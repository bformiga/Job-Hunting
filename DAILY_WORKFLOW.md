# Daily workflow

Spend roughly an hour on 3–5 prioritized applications. Use Apply Next for dated listings and Unknown Dates for manual review. Edit status, applied date, follow-up, and notes only in Jobs. The shortlist is a live queue; it does not limit daily submissions. Confirm graduation/start date and internship eligibility directly before applying. Internship listings are retained only when graduate eligibility is explicit and continued enrollment is not required. Salary is review-only; currency, period, base versus total compensation must be checked.
